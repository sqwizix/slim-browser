# Slim Browser 0.5.0

Russian and English shell localization and first public source distribution.

- `Language` accepts `ru-RU` and `en-US`; old Belarusian choices normalize to Russian.
- Menu, settings, permissions, download labels, accessibility strings and native
  application prompts use the selected language. WebView2 environment language
  requires a complete browser restart.
- User folder names, page titles and stored content are rendered verbatim.
- English and Russian project pages describe features, installation, development,
  dependencies, privacy limits and licensing. Screenshots use isolated test profiles.

Validation on Windows with the system WebView2 runtime:

- 35 Rust tests passed; 2 live network tests ignored by the default suite.
- 25 JavaScript tests passed, including language switching, placeholder integrity,
  backend message translation and preservation of user titles.
- 95 real WebView2 integration checks passed, including English settings and
  permission labels, Russian restoration, navigation, private profiles, cleanup,
  password origin isolation, downloads, extensions and Windows integration.
- `cargo fmt --check` and clippy with `-D warnings` passed.
- Russian and English interfaces were visually inspected in the running app.

Release assets: per-user Windows x64 MSI, portable ZIP, and SHA-256 checksums.
Original application source is MIT; bundled dependencies and filters retain
their licenses and notices. Executables are unsigned.
