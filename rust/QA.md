Платформа: Windows x64, локальный Rust 1.99.1 MSVC, системный WebView2 Evergreen.

Готовый файл в корне проекта: `artifacts/SlimBrowser-Rust/SlimBrowser-Rust.exe`. Размер финального EXE: 1 455 104 байта. Ресурсы и CRT встроены; проверка PE imports показывает системные Windows DLL, без .NET и отдельной CRT DLL.

Автоматические проверки финальной сборки:

- `cargo test --locked`: 14 тестов, все прошли.
- `cargo clippy --all-targets -- -D warnings`: без предупреждений.
- `cargo fmt --check`: успешно.
- `node --check ui/app.js`: успешно; Node используется только для этой проверки.
- `build-rust.ps1 -Test`: Release и 22 проверки с реальным WebView2 прошли. Полный отчёт — `artifacts/SlimBrowser-Rust/smoke-test.txt` в корне проекта.

Интеграционный тест использует новый временный профиль и виртуальные HTTPS-хосты с локальными fixture. Проверены UI IPC, отсутствие host bridge у сайтов, меню без обрезания последнего пункта, сохранение меню при передаче фокуса, настройки прозрачности без категории поиска, изоляция HTTPS-origin при автозаполнении, уничтожение/восстановление WebView неактивной вкладки, независимые маски очистки и реальные cookies, приватный профиль, изоляция приватных cookies, API расширений, сохранение закладок/настроек и ожидание очистки при закрытии последнего обычного окна.

В ходе ручной проверки в отдельных временных профилях проверены: светлая/тёмная темы, стекло Windows DWM и ползунок до 100 %, скрытие панели без смены вкладки, читаемость и доступность пунктов меню, вход в настройки, Ctrl+L с вводом URL, Ctrl+T с созданием одной вкладки и отображение внешней HTTPS-страницы. Тесты не использовали пользовательский WebView2-профиль и реальные пароли.

Во время QA исправлены: блокирование NavigateToString в новом WebView2 (интерфейс переведён на закрытый локальный HTTPS-origin), потеря меню при смене фокуса, повторение подписей и обрезание меню, непрозрачная подложка нативного окна, обработка клавиатуры в оболочке и события завершения устаревших навигаций. События навигации теперь сопоставляются по NavigationId; неуспешные переходы не добавляются в журнал и не запускают автозаполнение.

Не проверены вручную установка произвольных сторонних расширений, длительные загрузки, все варианты сайтов, высокие DPI и длительный стресс. Ограничения и порядок импорта данных описаны в README.

Скорость измеряется по фактической разнице полученных байтов с интервалом около секунды; при неизвестном Content-Length общий размер не выдумывается. Длительные внешние скачивания, обрывы сети и все варианты серверного возобновления отдельно не проверялись. Системный список загрузок WebView2 сохранён отдельной кнопкой.

## DNS только для браузера, компактные загрузки и каталог — 7 ноября 2026

Сборка: `artifacts/SlimBrowser-Rust-network/SlimBrowser-Rust.exe`, 3 915 264 байта. Рабочий профиль и DNS Windows не менялись. Основные проверки проводились в изолированных профилях.

- 24 локальных unit-теста и 65 проверок с настоящим WebView2 прошли. Дополнительно прошли два явных сетевых теста (`cargo test --locked live_ -- --ignored --nocapture`).
- Сетевой тест получил A и AAAA example.com по настоящему DoH Cloudflare с bootstrap на выбранный IP, затем успешно выполнил HTTPS-запрос через локальный SOCKS5 и собственный DNS. Проверены SOCKS5-передача реальных байтов, валидация IPv4/IPv6 и HTTPS, проверка DNS transaction ID и отклонение коротких ответов.
- В живой оболочке проверены переключение битов с множителем восемь, перенос масштаба во внешний вид, отсутствие прежнего раздела, четыре серверных блока DNS/DoH, размещение трёх строк загрузок без прокрутки и кнопки-иконки на одной строке с именем.
- С настоящих официальных страниц выпусков загружены и распакованы uBlock Origin Lite 2026.1103.1743, Dark Reader 4.9.135, Stylus 2.4.17. Проверены Manifest V3 и разрешения каждого пакета; эти версии были актуальны в момент теста, в коде они не фиксируются.
- Проверены отклонение ZIP с выходом за каталог, выбор пакета Chromium от нужного разработчика, диалог разрешений до установки и действительная установка тестового Manifest V3 расширения через AddBrowserExtension в отдельный тестовый профиль.
- `cargo clippy --all-targets --locked -- -D warnings`, `cargo fmt --check`, `node --check ui/app.js` и механический анализ интерфейса прошли. Вручную осмотрены внешний вид с масштабом и раздел сети; каталог открывается отдельным окном.

IPv6 как тип DNS-адреса поддерживается кодом и проверяется валидацией; подключение к внешнему DNS-серверу по IPv6 на этой машине отдельно не проверялось. Проверка ответов AAAA в сетевом тесте выполнялась через IPv4 DoH endpoint. Работа всех возможностей трёх расширений в WebView2 не проверена, что отдельно указано в интерфейсе каталога и README. Установленные пакеты не обновляются автоматически.
